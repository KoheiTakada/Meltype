# 05 入力エンジン

確定（段階1の範囲）

`engine` モジュールの仕様。ここに書くのは、未確定文字を作る配列（かな、ローマ字、英字フリック）での入力の動作。英字配列と数字・記号の配列は未確定文字を作らないので、エンジンを通らない。

## 入力セッション

入力欄1つにつき、入力セッションを1つ持つ。入力欄が切り替わったら、新しいセッションを始める。未確定文字として出ていた文字は、ふつうの文字として元の入力欄に残る（Android が、出ていた内容のまま未確定を終わらせる）。新しい入力欄には何も持ち込まない。このとき学習はさせない。

セッションが持つ状態:

| 状態 | 中身 |
| --- | --- |
| 読み | 利用者が打ったかなの並び。最大 100 文字 |
| 打ちかけの英字 | ローマ字配列で打った英字のうち、まだかなになっていないもの（[ローマ字入力](#ローマ字入力)）。ほかの配列ではいつも空 |
| 変換結果 | 読みを文節に区切り、各文節に候補を付けたもの。変換を頼んでいないとき、または結果がまだ返っていないときは空 |
| 選択中の候補 | 空白キーで選んでいる候補の番号。選んでいなければなし |

読みも打ちかけの英字も空のとき、未確定文字はない。

## 操作と結果

`app` から受け取る操作と、その結果。

### 文字を入れる

読みの末尾に文字を足す。読みが 100 文字に達していたら、先に未確定文字を確定してから足す。

選択中の候補があるときは、その候補を確定してから、新しい読みとして足す。

### 文字キーをタップ（トグル入力）

トグル入力（[04](04-keyboard-ui.md)）がオンのとき、文字キーのタップは「どのキーか」と「押した時刻」を付けて受け取る。

- 直前の操作が同じキーのタップで、その時刻から待ち時間以内なら、読みの最後の1文字を、そのキーの次の文字に置き換える。
- そうでなければ、「文字を入れる」と同じように、そのキーの最初の文字を足す。

タップと「戻す」以外の操作（フリックでの入力、濁点・半濁点・小文字、削除、空白、確定、候補のタップ、▶ キー）を受け取ると、切り替えは終わる。▶ キーは、切り替え中でなければ何もしない。

時刻は `app` が渡す。`engine` は自分で時計を見ない（テストで時刻を自由に決められるようにするため）。

待ち時間とオン・オフは、設定の値を `app` が `engine` に渡す。設定が変わったら、次のタップから新しい値で動く。

トグル入力がオフのとき、タップは「文字を入れる」と同じに扱う。

### 戻す

戻すキー（[04](04-keyboard-ui.md)）の操作。「押した時刻」を付けて受け取る。次の順に見て、最初に当てはまったものだけを行う。

1. 選択中の候補がある（または、変換結果を待ったまま空白が押されている）: 選択を解いて、ライブ変換の表示に戻す。文字は消さない。
2. 切り替えの途中（直前の操作が文字キーのタップか「戻す」で、その時刻から待ち時間以内）: 読みの最後の1文字を、そのキーの1つ前の文字に置き換える。最初の文字からは最後の文字に回る。切り替えは続き、待ち時間はこの操作の時刻から数え直す。
3. どちらでもない: 何もしない。

トグル入力がオフのとき、何も持たない欄（パスワード）のときは、2 に当てはまらない。変換しない欄で最後の1文字を持っているときは、2 が効く。

### 濁点・半濁点・小文字

読みの最後の1文字を、[04](04-keyboard-ui.md) の表の順に切り替える。

### 大文字・小文字

英字フリック配列の `a⇔A` キー（[04](04-keyboard-ui.md#大文字・小文字キー（a⇔A）)）の操作。持っている最後の1文字が英字なら、小文字と大文字を入れ替える。英字でなければ何もしない。

英字フリック配列では、セッションを「変換しない欄」と同じ動作にして使う（最後の1文字だけを持つ。[09](09-privacy-security.md)）。文字キーのタップ、フリック、トグル入力、戻す、削除は、かなのときと同じ操作で受け取る。キーに文字のない向きがあるとき、トグル入力は文字のある向きだけを回る。

### 削除

読みの最後の1文字を消す。選択中の候補があるときは、選択を解いてライブ変換の表示に戻すだけで、文字は消さない。

読みが空になったら、未確定文字をなくす。

### 空白（明示変換）

候補バーの次の変換候補を選ぶ。まだ何も選んでいないときは、いま表示している内容と違う最初の変換候補を選ぶ（ライブ変換で第一候補が出ているならその次、かなのまま出ているなら1番目）。最後の変換候補の次は最初に戻る。選んだ候補を未確定文字として表示する。

空白で選ぶのは変換候補だけ。変換候補は、読み全体を変換した結果、先頭の文節のほかの候補、読みそのまま（ひらがな）、読みをカタカナにしたもの。予測候補は候補バーには出すが、空白では選ばない（飛ばして次の変換候補へ進む）。予測候補を選ぶ方法はタップだけ。

理由: 予測候補には、前に確定した長い文が、打った分より長いまま出てくる。空白は「打った読みを変換する」ためのキーなので、打っていない文がそれで確定されてはいけない。

変換結果がまだ返っていないときは、返るのを待ってから最初の候補を選ぶ。

### 確定

いま未確定文字として表示している内容を確定し、読みを空にする。確定した内容を学習させる（[06](06-conversion-mozc.md)）。

### 候補をタップ

その候補を確定する。候補が読みの先頭の一部だけに対応するものなら、残りの読みは未確定のまま残し、ライブ変換を続ける。

## ローマ字入力

ローマ字配列（[04](04-keyboard-ui.md#ローマ字配列)）で打った英字を、かなに組み立てる。できたかなは読みの末尾に入り、そこから先（ライブ変換、候補、確定、学習）は、かな配列で打ったかなと同じに扱う。

### 打ちかけの英字

- まだかなになっていない英字を、打ちかけの英字と呼ぶ。入力セッションが、読みと並べて持つ。長くても 3 文字。
- 打ちかけが `n` ひとつのときは、それを仮の ん として扱う（下の「仮の ん」）。それ以外の打ちかけの英字は、次のとおり。
- 未確定文字として出すのは、読みの表示（[ライブ変換](#ライブ変換)の表のとおり）のあとに、打ちかけの英字を打ったまま半角で続けたもの。
- 変換するのは読みだけ。打ちかけの英字は Converter に渡さない。変換を頼むのは、読みが変わったときだけ（英字を打っても、読みが変わらなければ頼まない）。
- ライブ変換の 4 文字の境目は、読みの長さで数える。打ちかけの英字は数えない。
- 読みの上限（100 文字）も、読みの長さで数える。できたかなを足すと 100 文字を超えるときは、先に読みを確定してから、できたかなを新しい読みにする。打ちかけの英字はそのまま続く。
- 読みも打ちかけの英字もないとき、未確定文字はない。

### 仮の ん

打ちかけが `n` ひとつのあいだ、読みの末尾に ん があるものとして扱う。`nihonjin` と打って確定すれば、にほんじん の変換結果（日本人）が確定される。

- 変換を頼む読み、ライブ変換の表示、候補の一覧、空白・確定・候補のタップ、学習は、どれも「読み + ん」に対して働く。表示にも ん が出る（`n` とは出さない）。4 文字の境目と 100 文字の上限も、この ん を数える。
- セッションは、この ん が仮のものだと覚えておく。次に打つ字で決まる。
  - 母音か `y`: ん をやめて、な行に組み立て直す（`kan` + `a` → かな、`n` + `ya` → にゃ）。読みが変わるので、変換を頼み直す。
  - `n` か `'`: ん に決まる（`kann` → かん）。読みは変わらないので、頼み直さない。
  - ほかの子音や記号: ん に決まり、その字が次の打ちかけになる（`kanj` → かん + `j`）。
- 削除は、仮の ん を消す（`kan` で削除 → か）。
- 確定、候補のタップで読みの末尾まで確定したとき、ん に決まる。候補が読みの先頭の一部だけに対応するときは、残りの読みの末尾で、仮の ん のまま続く。
- 変換結果がまだ返っていないあいだの表示は、ライブ変換の表のとおり（直前の表示 + 新しく打ったかな。ここでは ん）。

### 組み立ての規則

英字を1つ受け取るたびに、打ちかけの英字の末尾に足して、次の順に見る。当てはまったら、残りについて最初から見直す。

1. 下の表の打ち方にちょうど一致する: そのかなを読みに足し、打ちかけを空にする。
2. 下の表のどれかの打ち方の、途中までに当たる（`k`、`ky`、`n` など）: 打ちかけのまま待つ。
3. 先頭が `n` で、1 にも 2 にも当たらない（`nk`、`ns` など。次が母音、`y`、`n`、`'` 以外）: ん を読みに足し、`n` を除いた残りを打ちかけにする（`shinb` → しん + `b`）。
4. 同じ子音が2つ続く（`kk`、`tt`、`ss`、`pp` など。`n` は除く）: っ を読みに足し、1つを打ちかけに残す（`kapp` → かっ + `p`）。`tc` も同じに扱う（`matc` → まっ + `c`、続けて `ha` で ちゃ）。
5. どれでもない（`kq` の `k`、`sht` の `s` と `h` など）: 先頭の1文字を、英字のまま読みに入れる。残りを打ちかけにする。読みに入った英字は、かなと同じに1文字として数え、変換にもそのまま渡す。

- ん の打ち方は `nn`、`n'`、`xn`、または `n` のあとに母音・`y`・`n` 以外の字。`nn` は、打ったところで ん に決まる。そのあとの母音は あ行のかなになる（`konnichiha` は こんいちは。こんにちは は、`n` を3つ続けて `konnnichiha` と打つ）。Mozc など、ほかの日本語入力と同じ規則。`n` が足りない打ち方を補うのは段階3（[08](08-auto-detection.md)）。
- 末尾に残った `n` ひとつは、仮の ん（上の「仮の ん」）。
- 4 の子音は、表の打ち方の先頭に出てくる子音（`n` を除く、英字の子音すべて）。
- 受け取るのは、英字の小文字と `-` `,` `.` `'`。大文字は受け取らない（app が確定してから直接入力する。[04](04-keyboard-ui.md#ローマ字配列)）。

### 操作ごとの扱い

打ちかけが `n` ひとつのときは、仮の ん として読みに入っているので、ここでの「打ちかけの英字」には当たらない。

| 操作 | 打ちかけの英字があるときの動作 |
| --- | --- |
| 英字を入れる | 上の規則で組み立てる。選択中の候補があるときは、いま出している内容（打ちかけの英字を含む）を確定してから、新しく組み立て始める |
| 削除 | 打ちかけの英字の最後の1文字を消す。打ちかけがなければ、読みの最後の1文字を消す。選択中の候補があるときは、選択を解くだけ（かな配列と同じ） |
| 空白 | 打ちかけの英字は、打ちかけのまま残し、読みの候補を選ぶ（表示は、選んだ候補 + 打ちかけの英字）。読みが空で打ちかけの英字だけのときは、その英字を打ったまま確定する（空白は入れない） |
| 確定 | いま出している内容を確定する。打ちかけの英字は打ったまま、末尾に付けて確定する。学習させるのは読みの分だけ |
| 候補をタップ | その候補を確定する。残りの読みと打ちかけの英字は、未確定のまま残る |

変換しない欄では、読みを作らず、できたかなを1回分ずつ持つ（[09](09-privacy-security.md)）。

## ライブ変換

読みが変わるたびに、読み全体の変換を `Converter` に頼む。

未確定文字として表示する内容:

| 条件 | 表示 |
| --- | --- |
| 読みが 4 文字未満 | 読みのまま（かな） |
| 読みが 4 文字以上で、変換結果が返っている | 各文節の第一候補をつなげたもの |
| 読みが 4 文字以上で、変換結果がまだ返っていない | 直前の表示のうち読みと対応が取れる部分 + 新しく打ったかな。対応が取れなければ読みのまま |
| 選択中の候補がある | その候補 |

4 文字という境目は、短い読みで勝手に漢字になって打ちにくくなるのを避けるため。Meltype と同じ値にしてある。短い語は空白キーか候補のタップで変換する。この値は定数1つで変えられるようにする。

変換結果が返ったとき、頼んだ時点の読みと今の読みが違っていたら、その結果は捨てる。

変換に失敗した、または 2 秒たっても返らないときは、読みのまま表示する。入力は止めない。

## 候補バーに並べる内容

読みがあるとき、次の順に並べる。同じ表記は2度出さない。予測候補がほかの種類の候補と同じ表記なら、予測候補のほうを出さない（空白で選べる候補が減らないようにする）。

1. 読み全体を変換した結果（各文節の第一候補をつなげたもの）
2. 読み全体に対する予測候補（Mozc が返すもの）
3. 先頭の文節の、ほかの候補
4. 読みそのまま（ひらがな）
5. 読みをカタカナにしたもの

読みが空のときは何も並べない。

2 が予測候補、それ以外が変換候補。空白キーが選ぶのは変換候補だけ（上の「空白（明示変換）」）。

3 の候補は、読みの先頭の一部だけに対応する。タップしたときの動作は上の「候補をタップ」のとおり。

## `app` に返す内容

操作のたびに、次の3つをまとめて返す。

| 項目 | 中身 |
| --- | --- |
| 確定する文字列 | 入力欄に書き込んで確定させる文字。なければ空 |
| 未確定文字 | 入力欄に下線付きで出す文字。なければ空 |
| 候補の一覧 | 候補バーに並べるもの。選択中の番号を含む |

`app` はこの順に入力欄へ反映する（先に確定、次に未確定）。
